## Database Schema - Supabase Tables

### User Tables (per user)
| Table | Description |
|-------|-------------|
| **User** | User account (id, email, name, image, isPremium, isBlocked, authProvider, streaks, etc.) |
| **UserSettings** | User preferences (theme, eyeTrackingEnabled, playback speed, watchBreak settings, etc.) |
| **Account** | NextAuth accounts (Google, credentials, Firebase auth) |
| **Session** | NextAuth sessions |
| **VerificationToken** | Email verification tokens |

### Content Tables (per user)
| Table | Description |
|-------|-------------|
| **Folder** | Folder organization (id, title, parentId, position) |
| **Playlist** | YouTube playlists (youtubeId, title, description, thumbnail, channelId, channelName, totalDuration) |
| **Video** | Videos (youtubeId, title, description, thumbnail, duration, position, playlistId, channelId) |
| **Channel** | User's subscribed channels (youtubeId, title, description, thumbnail, subscriberCount, isLive, liveVideoId) |
| **LibraryItem** | Items in folders (type: PLAYLIST/VIDEO, externalId, folderId, position) |

### Global Shared Cache Tables
| Table | Description |
|-------|-------------|
| **ChannelCache** | Global channel cache (youtubeId, title, description, thumbnail, uploadsPlaylistId, **lastSyncedAt**, **nextPageToken**) |
| **VideoCache** | Global video cache (youtubeId, title, description, thumbnail, duration, publishedAt, channelId, **isLive**) |

### Enums
- **LibraryItemType**: "PLAYLIST" | "VIDEO"
- **TodoType**: "TASK" | "PLAN" | "EVENT"

## Problem
- **Playlists**: Already modified to use RSS feed with API fallback
- **Channels**: Currently only uses YouTube API (no RSS feed, no caching strategy)
- **Goal**: Implement a complete quota-efficient fetching strategy with shared caching

## Proposed Solution: Ultimate YouTube Video Fetcher

### 1. Database Schema Updates Needed

**Add columns to ChannelCache table:**
- `lastSyncedAt` - already exists
- `nextPageToken` - already exists
- (Add if missing): `uploadsPlaylistId` - need to verify

**Add columns to VideoCache table:**
- `isLive` - **NEW** - to track live status
- `publishedAt` - already exists

### 2. Fetch Logic Workflow

```
User requests channel videos
       │
       ▼
┌──────────────────┐
│ Check Cache      │────Yes────► Return cached data
│ (VideoCache)     │
└────────┬─────────┘
         │ No/Empty
         ▼
┌──────────────────┐
│ RSS Check        │
│ (15 min freshness)│
└────────┬─────────┘
         │
    ┌────┴────┐
    │ >15 min │ Yes
    │ old?    │───────────► Fetch RSS (FREE)
    └─────────┘           Update DB, set lastSyncedAt
                          Return videos
         │ No (fresh)
         ▼
┌──────────────────┐
│ Deep Sync (API)  │────No videos?────► Brand new channel
│ 1 token/request │           │
└────────┬─────────┘           ▼
         │             Fetch from Uploads playlist
         │             (playlistItems.list)
         │             Store nextPageToken
         ▼
    Upsert to DB (shared cache)
    Return videos
```

### 3. "View More" Pagination Feature

```
User clicks "View More"
       │
       ▼
┌──────────────────┐
│ Get nextPageToken│
│ from ChannelCache│
└────────┬─────────┘
         │
    ┌────┴────┐
    │Token    │
    │exists?  │
    └────┬────┘
      Yes│    │No (use publishedBefore)
         ▼    ▼
┌──────────────────┐
│ API call with   │
│ pageToken OR    │
│ publishedBefore │
└────────┬─────────┘
         │
         ▼
    Upsert to DB
    Update nextPageToken
    Return next batch
```

### 4. RSS Feed URL
- Format: `https://www.youtube.com/feeds/videos.xml?channel_id={channel_id}`
- Returns ~15 most recent videos
- Cost: **FREE** (0 quota units)

### 5. API Endpoints Used
- `playlistItems.list` - cost: **1 unit** per request
- Get uploads playlist: channel ID prefix "UC" → replace with "UU"
